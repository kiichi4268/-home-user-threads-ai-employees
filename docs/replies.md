# 返信への答え方の台本（台本作成AI No.11・表現チェックAI No.16）

Threads の返信（会話）に答えるときの台本です。**答えるのは加藤さん**（Claude は投稿への返信を自動ではしない）。
CLAUDE.md「2. 絶対ルール」の内容だけで作っています。ここにない質問は推測で答えず、「DMでお気軽にどうぞ」に寄せる。

## 守ること
- 残り人数は書かない（「まだ参加枠あります」）。参加費は「1,500円（当日、現金またはPayPay）」。「一律」と書かない。
- 個人の連絡先は聞かない・書かない。出会いを連想させる言葉は使わない。
- 分からないこと（会場の最寄り駅が不明な会場など）は「DMでお気軽にどうぞ」。
- 返信の本文・返信した人の名前は、このリポジトリに残さない（よくある質問は「型」だけをこの表に足す）。

## よくある質問と答え方

| 質問の型 | 答え方（そのまま使える文） |
|---|---|
| 1人でも大丈夫？ | 大丈夫です！ほとんどの人が1人で参加しています😊 |
| 初心者・久しぶりでも平気？ | 平気です！初心者7割・経験者3割くらいなので、気軽に来てください。 |
| 何を持っていけばいい？ | 着替え・体育館シューズ・飲み物だけでOKです。バドミントンと卓球はラケットの貸出もあります。 |
| 参加費は？ | 1,500円です（当日、現金またはPayPay）。 |
| どうやって申し込むの？ | 公式LINE（https://lin.ee/WIbLPFV）に登録して、メニューの「イベントカレンダーから予約」からどうぞ。フォームのあとに出る合言葉をLINEに送ると「参加受付証」が届きます。 |
| 当日はどうすればいい？ | 会場で主催者に「参加受付証」を見せて、参加費を払うだけです。 |
| 当日はどんな流れ？ | 受付 → ストレッチ・基礎練習 → シャッフルゲーム（試合）→ 片付け → 解散、という流れです（例）。 |
| まだ空いてる？ | まだ参加枠あります！公式LINEから予約できます。 |
| 何歳くらいの人が来る？ | 20〜40代の社会人の方が中心です。 |
| 会場はどこ？（アクセスが分かる会場） | 日付ごとに CLAUDE.md「5. 日程」のアクセスをそのまま答える（例：代々木の杜は JR代々木駅から徒歩5分）。 |
| 会場はどこ？（アクセスが不明な会場） | 会場名だけ答え、「行き方はDMでお気軽にどうぞ」と添える。最寄り駅は書かない。 |
| どこが運営してるの？ | BARマカシェットが運営しています。 |
| それ以外 | 詳しくはDMでお気軽にどうぞ！ |
