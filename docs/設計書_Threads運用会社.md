## Instagram との違い
| | Instagram（稼働中） | Threads（案） |
|---|---|---|
| 主役 | 画像・動画（ストーリー・リール・カルーセル） | 文章（1投稿500字まで。画像・動画も付けられる） |
| 本文のURL | 書かない（押せない） | 書ける（公式LINEのリンクをそのまま置ける） |
| 伸びる要素 | 保存・シェア | 返信（会話）・再投稿 |
| 本数の目安 | ストーリー1日6本＋週4本 | 1日1〜2本（朝か昼） |
| 一番大事な数字 | リンクタップ（月110） | 公式LINEのリンクのクリック（案。目標は社長と決める） |
| 鍵の期限 | 期限なし | 60日（期限前に延長が必要。仕組みで見張る） |

## 再開するまでの流れ（社長がOKを出したら）
1. **社長・10分**：Threads の鍵を作って GitHub に登録（THREADS.md「2.」）
2. **Claude・1回**：投稿管理（24）・数値分析（27）を作る ➔ **済み**（tools/th_queue.py・th_insights.py）
3. **Claude・1回**：14日分の下書きを作って試運転 ➔ **下書きは済み**（11/11〜11/24）。社長が Merge したら自動投稿
4. **毎週**：Instagram と同じ PDCA に合流（日曜の週次で、Threads の「一番落ちている段」と「改善1つ」も決める）

GitHub アクセスは Instagram と共有（普段1日3回・最大4回）。Threads を足しても、制作の push はまとめて1回にする。
